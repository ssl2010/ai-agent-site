Privacy Policy

Effective: September 27, 2026

Overview

Sun's AI Agent is a private, owner-operated personal automation application. This policy explains how the application accesses, uses, stores, and shares Google user data when an authorized user connects a Google Account.

Google user data accessed

Depending on the features explicitly authorized by the user, the application may access:

  • Gmail message metadata, sender and recipient information, subject lines, message content, attachments, labels, and mailbox state.
  • Google Calendar calendars and events.
  • Google Drive files and metadata, including Google Docs and Google Sheets content selected for an enabled workflow.
  • Google Contacts data when a contacts feature is explicitly enabled.
  • Basic Google Account identity information required to associate an authorization with the correct account.

How data is used

Google user data is used only to provide user-requested features, including email summaries and urgent alerts, mailbox organization, calendar and travel automation, document handling, and expense-receipt organization. The application may mark messages as read, send mail, archive or delete messages, or create, update, and delete calendar events only when the relevant feature and permission have been authorized.

AI-assisted processing

To provide summaries and other user-facing assistance, bounded portions of relevant content may be sent to an AI processing service configured by the application owner, such as Zhipu AI, Google Gemini, OpenAI, or Tencent MaaS. Only data necessary for the requested feature is sent. Google user data is not used by Sun's AI Agent to train or improve generalized artificial-intelligence models.

Storage and retention

OAuth credentials and operational data are stored on access-controlled systems operated by the application owner. Email content and metadata may be cached locally for synchronization, numbering, summaries, auditability, and recovery. Data is retained only for as long as needed for those features or required operational recovery. Encrypted operational backups are rotated on a short retention schedule. Users may request deletion as described below.

Sharing and disclosure

Google user data is not sold, rented, used for advertising, or shared with data brokers. Data is disclosed only to service providers necessary to operate a user-requested feature, to comply with law, or to protect the security of the user and the service.

Security

The application uses OAuth rather than collecting Google passwords. Credentials are access-restricted, application services use least-privilege controls, and operational access is limited to the application owner and explicitly authorized operators. No security measure can guarantee absolute protection.

User controls and deletion

Users can revoke Google access from the Google Account connections page. To request deletion of cached Google user data and associated credentials, contact sun.shilei@gmail.com. A verified request will be handled within 30 days, subject to narrowly required security or legal records.

Google API Services User Data Policy

Sun's AI Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

This policy will be updated before Google user data is used for a materially different purpose. Questions may be sent to sun.shilei@gmail.com.
